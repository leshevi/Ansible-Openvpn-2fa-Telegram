Добавление двухфакторной аутентификации (2FA) превращает ваш VPN в настоящую «крепость». Теперь для подключения мало иметь файл сертификата — нужно будет ввести 6-значный код из приложения (Google Authenticator, Authy и т.д.).
Как это будет работать:
При попытке подключения OpenVPN запросит Username и Password.
В поле Username можно вводить что угодно (или имя клиента).
В поле Password нужно ввести 6-значный код из приложения на телефоне.
Как активировать 2FA для пользователя
После запуска плейбука 2FA не включится сама собой — нужно сгенерировать секретный ключ для конкретного человека.
Зайдите на сервер по SSH.
Выполните скрипт для нужного клиента:
bash
sudo /usr/local/bin/generate-2fa.sh client1

Скрипт выдаст секретный ключ и ссылку на QR-код.
Отсканируйте QR-код в приложении (Google Authenticator) на телефоне.
Итог
Теперь при подключении ваш OpenVPN-клиент (например, Tunnelblick на Mac, OpenVPN Connect на Windows/Android) покажет окно ввода логина и пароля. Вводите код из приложения в поле пароля.
Самое главное пароль доступа меняется каждые 10-30 сек. И при каждом подключении смотреть новый пароль и вставлять его в поле пароля.
